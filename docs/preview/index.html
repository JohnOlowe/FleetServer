How it works

ESP32 + GPS ──▶ same Wi-Fi / phone hotspot ──▶ phone :8080 ──▶ map + fleet list

The phone is the server. It runs as a foreground service, holds a Wi-Fi lock, and works with no internet at all (the offline map draws its own coordinate grid).

Any laptop on the same network can open http://<phone-ip>:8080/ and watch the same map in a browser — OSM tiles when the laptop has internet, the grid map when it does not.

What the ESP32 sends

POST /telemetry
{"device":"esp32-01","lat":7.377500,"lon":3.947000,
 "state":4,"sats":9,"speed":12.30,"heading":42.0}

Also accepted: GET /telemetry?lat=…&lon=…&state=… and a raw TCP line esp32-01,7.3775,3.9470,4. See docs/API.md.

Device states

1GPS device not found
2No GPS fix
3Offline mode (buffered fix)
4Operational
